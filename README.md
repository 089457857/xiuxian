# 萬妖仙途（0.2.0）

修仙題材的割草生存手遊：單手移動、功法自動施放，撐到最後打倒大妖。四大門派 × 正邪兩道 = 8 條支線。
名字是暫定的，想換隨時改 `xian-data.js` 的 `TITLE` 和 `index.html` 的 `<title>`。

## 0.2.0 更新
- **畫風：** 全面換成向量 Q 版，包括角色、所有妖獸、飛劍、技能特效、有花草樹石的地面，以及選單裡的頭像。
- **造型商店：** 時裝、武器（限本門派）、拖尾、光環、頭飾、稱號，可以試穿、購買、穿戴。
- **限定祈願：** 公開完整機率表、80 抽保底、每 10 抽至少一件史詩，重複的造型轉成碎片並可兌換，保存祈願紀錄。
- **仙玉取得：** 新角色送 320，突破小境界 +20，渡劫成功 +100，每日首勝 +20。
- **儲值（測試模式）：**
  - 六種仙玉禮包，買越多送越多，每個禮包第一次購買雙倍。
  - 修仙月卡：150 元立刻給 300 仙玉，之後 30 天每天領 50，最多累積 180 天。
  - 目前點了直接給仙玉、不扣錢，正式上架後改走 App 內購。
- **效能保護：** 手機跑不動時，會自動降低畫面解析度和同屏妖獸上限。

## 檔案
| 檔案 | 內容 |
|---|---|
| `index.html` | 遊戲畫面（局內戰鬥、所有選單） |
| `xian-art.js` | 向量 Q 版美術：角色分層、妖獸、武器造型、光環、地面（遊戲畫面先畫進快取再貼圖） |
| `xian-data.js` | 共用資料與規則：門派、功法、境界、妖獸、奇遇、死亡、轉換代價。伺服器和遊戲畫面用同一份，所有局外進度都由 `act()` 判定 |
| `server.js` | 帳號、雲端存檔、排行榜、成績驗證 |
| `manifest.json`、`icon.png` | 讓手機「加入主畫面」後全螢幕開啟 |
| `render.yaml` | Render 部署設定 |

## 部署（跟屁眼王國一樣）
1. 開一個新的 GitHub repo，把整個資料夾的檔案傳上去。
2. Render 新增 Web Service，連到這個 repo（或用 render.yaml）。Build：`npm install`，Start：`node server.js`。
3. 環境變數 `DATABASE_URL` 可以直接用屁眼王國那個 Postgres。`KV_KEY` 設成 `xiuxian`，資料就會跟其他遊戲分開存。
4. 沒有伺服器時（例如直接開 index.html），遊戲會自動進入「離線試玩」，進度存在手機上。

## 已定案的設計
### 正邪與轉換
- **分道：** 金丹期前的「心魔劫」（築基後期渡劫）決定正邪。道心在 ±20 以內可以自己選，超過就由道心決定。
- **道心：** 範圍 -100～+100。會被局內奇遇、學旁門功法（邪 -12、正 +4）推動。道心跟路線相反時，局內會出現心魔（碰到後方向顛倒）。同方向達 30 以上叫「道心穩固」，傷害 +10%。
- **入魔（正 → 邪）：** 不掉境界，但會被逐出師門。
- **回頭是岸（邪 → 正）：** 散功掉一個小境界（最低金丹初期），通過「洗心池」試煉。之後 10 局有業障，心魔會找上門。
- **叛出師門：** 散功掉一個大境界（最低築基初期），通過新門派的入門試煉。同時改正邪的話，再多掉一個小境界。
- **叛徒追殺：** 原門派追殺 15 局，追殺者依序是外門弟子、內門師兄、長老、掌門，越來越強。殺到掌門就能提前了斷。追殺者會用原門派的招式。
- **負荊請罪：** 回到原門派要再掉一個大境界，並熬過「宗門懲戒」。此生只能回去一次，之後不能再叛。
- **重修加成：** 散功後重修，修為 ×1.5，直到回到原本的境界。
- **冷卻：** 轉正邪後 20 局、換門派後 30 局內不能再轉換。

### 死亡三層
1. **一般關卡陣亡：** 這局的戰利品只帶回一半。
2. **渡劫失敗：** 掉一個小境界，並重傷 3 局（屬性 ×0.8）。
3. **禁地陣亡（身死道消）：** 奪舍重生，掉一個大境界，隨機碎一件法寶。
   - **替死傀儡：** 花 4000 靈石買，可以擋一次。
   - **元嬰出竅：** 元嬰期以上才有，逃過一劫後元嬰受損 5 局，冷卻 10 局。

**一命修仙（硬核）：** 任何死亡都會讓角色永久消失，不能用保命手段。作為交換，修為 ×1.3，並且上專屬排行榜。

### 局內
- **一局流程：** 一般關卡 5 分鐘後大妖現身。渡劫關卡 3 分鐘，期間天雷會一直落下。禁地的妖獸更強、收益 ×2。
- **升級三選一：** 選項包括本門功法、通用心法（被動）、稀有的旁門功法（一局限一門、不能大成，會影響道心）。
- **大成：** 路線主招式練到 5 級，並且帶著對應的心法，就會出現大成選項。8 條支線各有一個大成招式。
- **奇遇：** 每局約第 80 秒和第 190 秒各出現一次，選正或選邪。
- **掉落：** 菁英怪會掉仙桃（回血）和聚靈符（吸取全場靈氣）。

### 美術方向（已定案）
- **風格：** 向量 Q 版（大頭、圓潤描邊、漸層與光暈），樣品在 `xiuxian-art/`。
- **換裝：** 角色分層繪製（後髮、披風、道袍、花紋、頭飾、武器、光環），每一層都能單獨替換。

### 造型商店（已定案）
- **原則：** 只賣外觀，不賣數值。特效不能改變範圍與打擊感，也不能擋住妖獸和預警圈。
- **正邪變色：** 墮入邪道時，時裝自動套上暗色系，但款式不變。
- **類型：** 武器造型、時裝、髮型與頭飾、技能特效（飛劍拖尾等）、光環與腳印、稱號。
- **適用範圍：** 武器造型限定門派；時裝、髮型、光環、特效全門派通用。
- **商店分三層：**
  - **一般商店：** 用靈石（打怪賺）買。
  - **精品商店：** 用仙玉（真錢）買。
  - **限定祈願（抽獎）：** 用仙玉抽，必須公開機率（台灣機率型商品規定）。
- **祈願規則：**
  - 80 抽保底必出傳說。
  - 重複的造型轉成「仙緣碎片」，碎片可以兌換指定造型。
  - 每日任務、成就、活動會送少量仙玉。
  - 保存每一抽的祈願紀錄。
- **儲值：** 上架後必須走 Apple、Google 內購，平台抽 15～30%。等確定要上架時再接。

### 野外（即時連線版，已定案）
- **地圖配置：** 正方形。
  - **四個角：** 四大門派的正道領地。
  - **四條邊的中點：** 四條邪道支線的據點（血魔劍、萬蠱、幽冥鬼道、修羅）。
  - **中間：** 殺戮區。
  - **最中心：** 禁地。
- **由外往內：**
  - **領地：** 受自家守軍保護。
  - **殺戮區：** 可以 PK，掉落更好。
  - **禁地：** 可以 PK，在這裡被殺就是身死道消。世界王每天固定時段在這裡出現。
- **守軍：** 擋得住一般人，單人闖不進去。組隊的高手清掉守軍後可以硬闖，偷取特產材料或摧毀敵方「靈脈」（讓整個勢力的修為獲得暫時下降）。守軍被打倒後要一段時間才會重生。
- **撤離：** 撿到的東西要走到傳送陣，或念完 5 秒回城符（被打會中斷）才算收進背包。
- **被 PK：** 掉這趟撿到的東西，殺人者可以撿走。裝備和造型不會掉。
- **沒有新手保護：** 新手想避開廝殺，可以待在自家領地或外圍。
- **道心連動：** 正道殺無辜的人道心大幅往邪偏；正道殺邪修算除魔，道心往正、領賞；邪修殺人不受懲罰，但會被當成獵物。
- **人數：** 每張圖 30～50 人，滿了就開分線。

### 之後即時連線版要做的（已定案，程式已預留架構）
- **秘境：** 共享野外地圖，多人同一張地圖刷怪，怪數比單人關卡少但更強。
- **搶怪：** 經驗依傷害比例分，稀有掉落誰先撿到就是誰的。
- **PK：** 只能在爭奪區和禁地，新手區和城鎮禁止，境界差太多也不能互打。
  - 被 PK 只算第一層死亡；在禁地被殺才會身死道消。
  - 硬核玩家可以進 PK 區，但進場前會再警告一次。
- **追殺令：** 原門派的真人玩家也能接追殺令，追殺叛徒領賞金。

## 調整數值去哪裡改
- **造型、價格、祈願機率：** `xian-data.js` 的 `COS`、`GACHA`、`JADE`。
- **升級需要的修為：** `xian-data.js` 的 `NEED`。
- **一局給多少修為、靈石：** `settleRun` 開頭那幾行。
- **功法強度：** `SK` 裡每招的 `base`（dmg 傷害倍率、cd 冷卻、cnt 數量）。
- **妖獸強度：** `MON`，以及 `MAPMUL`（每張地圖的倍率）。
- **局內刷怪速度：** `index.html` 的 `spawner()`。
- **規則數字**（冷卻局數、懲罰局數、硬核加成等）：`RULE`。

## 防作弊
- 伺服器會記錄每局的開始時間。回報的秒數比實際經過的時間還長，這局就作廢。
- 擊殺數有上限：每秒最多 14 隻。
- 打倒大妖必須真的撐完整局時間才算。
- 所有進度都由伺服器用同一份規則計算，客戶端不能直接改數字。

之後做即時連線時，再把局內戰鬥搬到伺服器跑。

## 儲值與上架內購
- **商品設定：** `xian-data.js` 的 `PAY`（禮包內容、價格、月卡）。
- **發放邏輯：** 所有儲值都經過 `payGrant(p, 商品代號, 訂單編號)`，同一筆訂單編號不會重複發放，累計儲值金額記在 `p.paid`。
- **測試模式：** 伺服器預設開著。正式上架時設定環境變數 `PAY_TEST=0`，關掉測試儲值。
- **上架時要做的：**
  1. 在 App Store Connect、Google Play Console 建立同樣代號的商品（p60、p330、p680、p1280、p3280、p6480、card）。
  2. App 用內購外掛（例如 Capacitor 的內購套件或 RevenueCat）完成付款。
  3. 在 `server.js` 預留的 `/api/iap/apple`、`/api/iap/google` 驗證收據，確認後呼叫 `D.payGrant`。
- **注意：** 在 App 裡賣虛擬貨幣必須走平台內購（抽 15～30%）。綠界等第三方金流的超商代碼不能用於遊戲儲值。

## App 版（Android 先上）
App 版就是把同一個網頁遊戲用 Capacitor 包起來，連到你部署在 Render 的伺服器。檔案都在 `app/` 資料夾，Render 部署不受影響。

| 檔案 | 內容 |
|---|---|
| `app/app-config.json` | **App 要連的伺服器網址**、App 代號、App 名稱 |
| `app/build-app.js` | 把遊戲複製進 App，並寫入伺服器網址 |
| `app/android/` | Android 專案（已設定好圖示、啟動畫面、自動版本號、簽章） |
| `.github/workflows/android.yml` | 推上 GitHub 就自動打包：測試用 APK，有金鑰時再加上架用 AAB |
| `.github/workflows/make-upload-key.yml` | 一次性：產生上架用的上傳金鑰 |
| `privacy.html` | 隱私權政策（上架必填的網址：`你的Render網址/privacy.html`） |
| `store/` | Google Play 商店圖示 512×512、橫幅 1024×500 |

### 一、部署伺服器
1. 開新的 GitHub repo，上傳這個資料夾的所有檔案（包含隱藏的 `.github` 資料夾）。
2. Render → New → Web Service，連到這個 repo。Build：`npm install`，Start：`node server.js`。
3. 環境變數：`DATABASE_URL`（可以共用屁眼王國的 Postgres）、`KV_KEY` = `xiuxian`。
4. 記下 Render 給的網址，例如 `https://xiuxian-xxxx.onrender.com`。

### 二、設定 App
1. 打開 `app/app-config.json`，把 `server` 改成你的 Render 網址。
2. **`appId` 一旦上架就永遠不能改**。目前是 `tw.wanyao.xiantu`，想換的話現在改（只能用英文小寫、數字和點）。
3. 打開 `privacy.html`，把「請填寫你的聯絡信箱」換成你的信箱。

### 三、打包測試用 APK（不用任何金鑰）
1. 把修改推上 GitHub，到 repo 的 **Actions** 分頁，會看到「打包 Android App」自動開始跑（也可以手動按 Run workflow）。
2. 跑完（約 5～10 分鐘）點進去，最下面 Artifacts 下載「萬妖仙途-測試版-APK」。
3. 解壓縮後把 .apk 傳到 Android 手機安裝（要允許「安裝不明來源應用程式」）。

### 四、上架用的 AAB（申請好 Google Play 帳號後再做）
1. repo → Settings → Secrets and variables → Actions → New repository secret：
   名稱 `ANDROID_KEYSTORE_PASSWORD`，值自己取一組密碼（記下來）。
2. Actions → 「產生上傳金鑰（只做一次）」→ Run workflow，跑完下載 upload-key。
3. 打開 `upload.jks.base64.txt`，把全部內容新增成 Secret：名稱 `ANDROID_KEYSTORE_BASE64`。
4. 把 `upload.jks` 和密碼備份到安全的地方（雲端硬碟加密資料夾之類）。Google Play 預設會幫你保管正式簽章金鑰，上傳金鑰弄丟了可以向 Google 申請重設，但還是要好好保管。
5. 之後每次打包都會多一個「萬妖仙途-上架用-AAB」，就是上傳到 Google Play 的檔案。版本號會自動遞增。

### 上架商店時要用到
- 隱私權政策網址：`https://你的Render網址/privacy.html`
- 刪除帳號方式：主畫面 → 帳號設定 → 刪除帳號（需要輸入密碼）
- 圖示與橫幅：`store/` 資料夾
- App 版一定要連伺服器才能玩。免費版 Render 閒置會睡著，開 App 時最多要等約一分鐘喚醒；正式上架建議升級付費方案。
